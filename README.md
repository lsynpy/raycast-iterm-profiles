# iTerm Profiles

Raycast extension to open iTerm2 with a selected profile.

## Install

1. Open Raycast → **Import Extension**
2. Select this folder

## Usage

1. Open Raycast
2. Search for **Open iTerm Profile**
3. Select a profile from the list to open a new iTerm2 window with that profile

## Development

```bash
npm install
npm run dev    # build and watch for changes
npm run build  # production build
npm run lint   # run eslint
```
